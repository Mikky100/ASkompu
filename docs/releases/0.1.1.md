# ASkompu 0.1.1 — Verified prototype

Released 6 November 2026, tag `0.1.1`.

Implements issues [#6](https://github.com/Mikky100/ASkompu/issues/6),
[#7](https://github.com/Mikky100/ASkompu/issues/7),
[#8](https://github.com/Mikky100/ASkompu/issues/8) and
[#9](https://github.com/Mikky100/ASkompu/issues/9): delayed ULA/MLA interval
activation, session-only display power control, speed-based internal trip
precision, and pulse diagnostics.

## Verification

- 147/147 deterministic native tests passed.
- `native`, `lilygo-main` and `esp32s3-ili9488-main` builds passed with the
  pinned PlatformIO configuration.
- 10,000 accepted pulses at 212 mm/pulse produced exactly 2,120,000 mm at
  20, approximately 94.34, 166.67 and 262.05 Hz in software tests, with rejected
  short edges and display-model/diagnostic reads.
- Tests cover ULA/MLA departure timing, repeated ticks, past/corrected starts,
  midnight, hysteresis thresholds/dwell/reset, signed trip formatting,
  diagnostic reset isolation and timestamp rollover.
- The pulse ISR was checked in the ELF's IRAM section.
- The ILI9488 firmware was installed through COM7 on an ESP32-S3 revision 0.2
  with 8 MB PSRAM. Every written flash region passed esptool hash verification.
  The NVS area was preserved.
- Live USB diagnostics responded with GPIO40 FALLING, 212 mm/pulse and a
  3816 µs minimum interval. Diagnostic capture/reset was exercised, with no
  pulses supplied during this device check.

## Published binaries

Release archives contain application firmware, bootloader, partition table,
boot_app0, ELF and a flash-layout manifest for each board. The source code is
the same as the tested/installed build; release preparation changed documentation

## Remaining physical verification

The known-count physical pulse-generator test while SPI refresh and USB output
are active, physical power/wake button checks, and in-car readability tests
have not been performed for this release. LilyGO was built and native-tested,
but this release was installed only on the ESP32-S3 ILI9488 device.

“Verified” describes the checks above; it does not mean complete in-car or
electrical validation. Issue #9 supplies measurements to investigate intermittent
speed halving; it does not claim to fix its underlying cause. Hardware acceptance
items in the issues remain open.

USB at 115200: `p` captures/dumps pulse diagnostics; `r` resets diagnostics only.
Menu: Järjestelmä → Diagnostiikka → Right. Power controls:
Järjestelmä → Painikeasetukset.
