# ASkompu 0.1.2 — Verified prototype

Release baseline: the latest implementation produced in the Codex conversation,
not the older 0.1.0 tree used accidentally for 0.1.1.

## Included GitHub issues

- #6: JAT+ULA/MLA first-interval timing at the accepted departure time
- #7: power button disabled by default for each session and display shutdown
- #8: trip presentation precision selected by speed with hysteresis
- #9: pulse input diagnostics, history and USB report
- #10: faster foot-reset response (5 ms software debounce)
- #11: one wrapping route-order continuation choice
- #12: move display shutdown to the main menu after System (sub-issue of #7)

The #7 shutdown placement is intentionally changed from the original issue:
`SAMMUTA NAYTTO` is the last main-menu item, immediately after `JARJESTELMA`.
Opening the main menu with Up selects it first. The button-settings submenu only
contains the session-local physical power-button enable/disable choice.
